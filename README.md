# ShadyPenguinn · Starter Ability Roller

Ability randomizer for ShadyPenguinn "choose our starter" videos.

**Play it:** https://shadypenguinn.github.io/ability-roller/

- 7 categories (Elite, Offensive, Defensive, Utility, Mediocre, Bad, Awful). Each one can be used once per run.
- Each roll shows 3 abilities from the category; you keep one.
- Costs and bonuses are split evenly across all 6 base stats.
- The pool is every ability usable in Pokémon Scarlet/Violet or Pokémon Champions, except Mega Tatsugiri's new ability.
- In Settings you can ban abilities, move them to another category, or change costs. Your progress saves in your own browser.
